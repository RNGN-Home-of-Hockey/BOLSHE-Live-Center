# Журнал решений

## 2026-10-13

- Репозиторий: `RNGN-Home-of-Hockey/BOLSHE-Live-Center` (публичный) — решение владельца.
  Поэтому личные данные участников и секреты сюда не попадают никогда.
- Обсуждение приложения — ветка `discussion` (идеи, отзывы со скриншотами, макеты).
- Выход приложения — **1 ноября 2026**; тестовая копия — гораздо раньше.
- В первый приоритет добавлены: вопрос ведущему, коллекционные карточки, уровни (XP) и
  достижения (по макетам), бусты и звёзды канала.
- Для статистики берём и Tennis Abstract (Elo) — только разрешённые для роботов страницы.
- Каждое фэнтези — своя группа участников и новый драфт; архив хранит число участников.
- Бота владелец создаст сам, когда будет готова первая база игроков.
- Ведущие: Мыскина, Авакова, Тартакова, Аношин, Знаменский, Володько, Кузнецов, Куклин,
  Донской, Сафина.
- Технологии: Node.js (тот же JavaScript, что в Cloudflare Worker у HOH), база — схема D1;
  первая база собирается локально в SQLite той же схемы.
- «Россиянин» определяется по спортивному гражданству (флаг, за кого выступает), не по паспорту.
