## Склейка игроков

Основа — рейтинги Flashscore (их номера используются в лентах матчей). К ним приклеиваются:
WTA по имени, Wikidata по номеру или по имени (с проверкой даты рождения), Elo по номеру
Tennis Abstract, фэнтези по имени. Китайские имена сравниваются «по буквам»
(«Xinyu Wang» = «Wang Xin Yu»).

**Русское имя** — по приоритету: решение админа в боте (навсегда) → ручная правка в файле → sports.ru →
фэнтези (проверено редакцией) → Wikidata → Flashscore → транскрипция по языку страны (`translit`).
Если другой источник пишет то же имя через «ё» — берём с «ё» («Рублёв»). Написание из расписания
«Больше» используется только чтобы узнать игрока (в таблице бывают опечатки), не для показа.

**«Россиянин»** — по спортивному гражданству, а не по паспорту: Бублик (Казахстан) и Циципас (Греция)
имеют российское гражданство в Wikidata, но не россияне для приложения. Под флагом «Мир» —
россияне и белорусы, различаем по WTA и Wikidata; если данных нет — считаем россиянином
с пометкой `neutral_flag_guess`.
