# Гранд-план: хайлайты всех главных матчей сезона 2026

Цель — чтобы в приложении у каждого главного игрока были лёгкие хайлайты (≈1–1,5 Мбит/с) всех его
крупных матчей сезона, которые показывал «Больше». Режет «Теннисный пульт» на нашем московском сервере
(RNGN-HoH-Highlights, ветка `tennis`): обзор матча по сетам, топ-3/топ-5 и ролики каждого сета. Готовое
само появляется в приложении у игрока и в карточке матча (ops/hl-push → /api/highlights/push).

Посчитано по истории наших эфиров (таблица эфиров «Больше», 17.10.2026).

## Сколько это по времени и месту

- **Нарезка.** Двухчасовой матч WTA режется на сервере примерно за 30–40 минут (распознавание счёта,
  звук, поиск подачи). Днём сервер свободен ~12 часов: при одной нарезке за раз — 18–24 матча в день,
  при двух — 35–40. Волна 1 — 2–3 недели, все три волны — 5–8 недель.
- **Скачивание.** Оригинал матча 1080p — 3–6 ГБ, после нарезки удаляется; на диске одновременно
  держим не больше 2–3 оригиналов.
- **Хранение лёгких копий** (≈1,3 Мбит/с, как сейчас): обзор ≈ 45 МБ, топ ≈ 20 МБ, ролики сетов
  ≈ 60 МБ → ~125 МБ на матч. 1 250 матчей ≈ **155 ГБ** (только обзор + топ ≈ 80 ГБ). На сервере
  1,8 ТБ — хватает с запасом.
- **Тяжёлые копии** (6 Мбит/с, ≈ 450 МБ на матч) для редакции — 560 ГБ на все волны. Предлагаю
  хранить их только для группы A и для финалов, остальное — 30 дней.
- **Проверка людьми.** Обзор смотреть ~5 минут: все 1 250 — около 100 часов. Предлагаю выборочно:
  каждый 10-й матч и все финалы — ≈ 12 часов.

## Что нужно сделать до запуска

1. **Профиль ATP для распознавания счёта.** Сейчас пульт режет WTA и челленджеры; у ATP своя
   графика счёта — 492 эфира ждут профиль.
2. **Очередь из списка.** Пульт режет отмеченные матчи; нужна загрузка списка волны (ключи эфиров)
   и ночная пауза на время хоккея.
3. **Видео по посту ВК** для февраля–июня — через ключ ВК с доступом к видео.
4. **Качество.** Доля распознанных очков сейчас 54–93% в зависимости от трансляции; матчи ниже 70%
   откладываем на ручную проверку.

## Решения за владельцем

- Подтвердить группы и порядок волн (A и B целиком; C — нужна ли).
- «Почти все» матчи топ-20: режем все или пропускаем разгромы ранних кругов (6:0 6:1)?
- Хранить ли тяжёлые копии и сколько.
- Ролики отдельных сетов в архиве: оставлять или хранить только обзор + топ.
