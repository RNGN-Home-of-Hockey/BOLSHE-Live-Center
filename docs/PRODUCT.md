# Продукт: «Больше. Теннис» в Telegram

Обновлено: 2026-10-13. Источники: созвон владельца с Лизой (редакция «Больше»), ответы владельца
на план, макеты уровней и достижений (ветка `discussion`, `docs/discussion/refs/`).

## Зачем

Приложение для теннисных людей, которым удобно пользоваться **каждый день**: расписание, счёт,
«наши», подписка на игроков, понятная статистика. Плюс игра — прогнозы, уровни, фэнтези —
чтобы человек не просто читал, а участвовал. Ставки (партнёр — Winline) — потом и аккуратно:
сначала востребованность, потом монетизация.

## Первый приоритет (к выходу 1 ноября)

1. **Каждый день:** матчи сегодня (отметка — что показывает «Больше», ссылка на трансляцию),
   счёт по ходу матча, результаты, блок «Наши», подписка ★ на игрока и уведомления.
2. **«Теннис для чайников»** — карточка матча простыми словами: форма, личные встречи, покрытие,
   рейтинг Elo («шансы примерно 64 на 36»), кто фаворит и почему.
3. **Прогнозы «Кто победит?»** — выбор победителя и **точного счёта по сетам**, проценты
   сообщества, голоса ведущих (как у Sofascore: два игрока, ниже — кто из ведущих за кого).
4. **Уровни и опыт (XP)** — теннисные (решение владельца: «придумай сам»), код `src/game/levels.js`:

   | Уровень | Подпись | XP от |
   |---|---|---|
   | Подающий мячи | Только вышел на корт | 0 |
   | Любитель | Играет по выходным | 100 |
   | Юниор | Освоил основы | 300 |
   | Квалификант | Пробился через квалификацию | 600 |
   | Игрок тура | Свой в основной сетке | 1 000 |
   | Сеяный | Его уже опасаются | 1 600 |
   | Топ-10 | Один из лучших | 2 500 |
   | Первая ракетка | Лучший из лучших | 3 700 |
   | Легенда | Обладатель Большого шлема | 5 000 |

   После «Легенды» каждые 2 500 XP — ещё один «титул Большого шлема». Карточка профиля — как в макете
   (уровень, подпись, XP, «до уровня …», полоса прогресса).
5. **Достижения** (по макету):
   - Горячая серия — 5 верных прогнозов подряд;
   - Охотник за сенсациями — угадал 3 неожиданные победы;
   - Король грунта — лучший результат на грунтовых турнирах;
   - Снайпер — угадал точный счёт 5 раз;
   - Против большинства — выиграл 3 прогноза вопреки общему выбору;
   - Лучше эксперта — обошёл ведущего по итогам турнира.
6. **Рубрики ведущих:** «Матч дня», «Недооценённый игрок», «Игрок, за которым надо следить»,
   голосование редакции за матчи.
7. **Вопрос ведущему** — человек задаёт вопрос в приложении, редакция отбирает, ведущий отвечает.
8. **Коллекционные карточки** — только развлечение: выдаются за достижения, без продажи и обмена.
9. **Бусты и звёзды канала** — учёт по каждому человеку, рейтинг самых активных, награда месяца
   (что именно позволяет Telegram — см. ниже).
10. **Фэнтези итоговых турниров** — отдельная вкладка. По 8 игроков в турнире, поэтому нужна
    «математика», которая разводит одинаковые команды (капитан, прогноз чемпиона/финалиста,
    вопрос на тай-брейк — например, сколько геймов будет в финале).

### Фэнтези: правила владельца

- У каждого фэнтези **своя группа участников**: каждый новый драфт проходит заново.
- Старые фэнтези храним в архиве и помним, **сколько человек участвовало каждый раз**
  (таблица `fantasy_contests`; RG-2026: 862 зарегистрировались, 825 полных команд).
- Из RG-2026 берём движок: очки считаются по цепочке «матчи → очки игроков → команды →
  таблица», пересчёт с нуля в любой момент; рассылки — только через очередь, не больше двух в день.

### Черновик начисления XP (обсуждаем)

| Действие | XP |
|---|---|
| Сделал прогноз на матч | +10 |
| Угадал победителя | +20 |
| Угадал точный счёт по сетам | +50 |
| Угадал вопреки большинству (за игрока выбрали < 35%) | ×2 к начислению |
| Ежедневный вход / серия дней | +5 за день серии |
| Участие в фэнтези турнира | +100 |

### Бусты и звёзды: что умеет Telegram (проверено по Bot API 10.3)

- **Бусты — да, по каждому человеку.** Бот-админ канала получает событие о каждом новом бусте
  (`chat_boost`, `removed_chat_boost`) и может спросить про любого пользователя приложения
  (`getUserChatBoosts`). Рейтинг «кто больше бустит» строим сами.
- **Звёзды — да, если платят через нашего бота** (счёт в Stars, платный контент, подписка):
  каждая транзакция видна с отправителем (`getStarTransactions`). Звёзды-реакции на посты
  канала Bot API по людям не отдаёт — их посчитать не сможем.

## После выхода (к Australian Open, январь 2027)

Сетка Большого шлема целиком (конкурс «угадай всю сетку»), обзоры матчей прямо в приложении
(из проекта хайлайтов), плашки для трансляций (как пульт /broadcast в HOH), интеграция Winline,
перенос прогнозов и уровней в хоккейное приложение HOH.

## Риски, которые держим в голове

- Призы за прогнозы и «угадай сетку» — нужна консультация юриста (граница «конкурс/лотерея»).
- Реклама ставок — 18+, маркировка партнёра.
- Flashscore — неофициальный источник: держим запасные (WTA API, ESPN, Wikidata, Tennis Abstract).
