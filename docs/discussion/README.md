# Ветка обсуждения приложения

Здесь — всё, что обсуждаем, а не код: идеи, отзывы тестировщиков, макеты, вопросы к редакции.
Код и база живут в ветке `main`; решения, которые приняты, переносятся в `main` → `docs/DECISIONS.md`.

## Как пользоваться

- Один разговор / одна порция отзывов = один файл `ГГГГ-ММ-ДД-тема.md`.
- Скриншоты и макеты — в `refs/` с датой в имени.
- Отзыв на тестовую копию: что открыл → что увидел → что хочется (скрин обязательно).
- Личные данные (телефоны, Telegram-номера участников, призовые списки) сюда не кладём:
  репозиторий публичный.
