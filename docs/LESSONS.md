# Уроки HOH Live Center и RG Fantasy

## Что повторяем из HOH Live Center

- Cloudflare Worker + D1 + бот + Mini App, автотесты в GitHub Actions.
- Имена строго по-русски везде; блок «Наши» включён по умолчанию.
- Режим «без спойлеров» (глаз) — люди смотрят записи.
- Рядом с длинной выборкой — свежая форма («последние 8»): так просили комментаторы.
- Картинки с запасным вариантом: нет обложки → логотип/фото, ошибка запоминается, а не повторяется.

## Ошибки HOH, которые не повторяем

| В HOH | Здесь |
|---|---|
| 18 слоёв «заплаток» в Mini App (v9→v28), наблюдатели DOM перехватывают клики друг друга, бесконечная перерисовка главной | Одна чистая структура экранов с первого дня |
| Бот опрашивает Telegram раз в минуту — ответ до 35 секунд | Вебхук: ответ сразу |
| Нет тестовой копии: пуш в main сразу уходит в рабочую версию | Отдельная тестовая копия; Лиза тестирует её |
| Пульт оператора без пароля | Админ-функции закрыты |
| Статистика «по итоговому счёту» вместо правил ставок (ОТ/буллиты) | В теннисе: отказы и снятия считаем отдельно, правила рынков Winline — заранее |
| Проверка после деплоя краснеет, когда источник пуст (нет матчей) | Проверки отличают «нет матчей» от «сломалось» |

## Что берём из RG Fantasy

- Источник истины — матчи. Цепочка: матчи → очки игроков → очки команд → таблица. Пересчёт
  с нуля даёт тот же результат (повторный запуск не удваивает очки).
- Массовые сообщения — только через очередь: метка от повторов, скорость 1 сообщение/сек,
  обработка ошибок Telegram (429 — пауза, 403 — человек заблокировал бота), не больше 2 рассылок в день.
- Админ видит доставку человеческим языком: «создано 825, отправлено 312, осталось 513».
- Сопоставление игроков: варианты написания + список «не узнанных».
- Админ не меняет спортивные результаты руками.

## Чего не берём из RG Fantasy

- Google-таблицу как базу и Apps Script как сервер: файл кода вырос до 3 МБ, лимиты Google
  ломали рассылки. Здесь база — D1, логика — Worker.
